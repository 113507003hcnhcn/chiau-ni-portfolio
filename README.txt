# 洪巧倪 Chiau Ni Hing｜個人網站

## 檔案內容
- `index.html`：個人網站首頁與全部區塊
- `assets/profile.jpg`：首頁個人照片

## 在 GitHub Pages 發布
1. 登入 GitHub，建立一個新的 Repository。
2. Repository 名稱可設為 `你的GitHub帳號.github.io`（若想使用個人首頁網址），或使用其他名稱。
3. 將 `index.html` 與 `assets` 資料夾一起上傳到 Repository 根目錄。
4. 若使用一般 Repository：進入 Settings → Pages → Build and deployment，Source 選擇 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
5. 等待 GitHub Pages 部署完成，網址通常會是 `https://你的GitHub帳號.github.io/Repository名稱/`。若 Repository 名稱是 `你的GitHub帳號.github.io`，網址通常是 `https://你的GitHub帳號.github.io/`。

## 發布前請檢查
- 請確認五項經歷的職稱與描述符合實際情況；目前文字是依照先前討論整理的初稿。
- 可將年度主題展覽等更具體的作品名稱補進 SELECTED WORKS。
- GitHub Pages 網址發布後，請用手機和電腦各測試一次。
- 名片 QR Code 請連到正式發布後的網站網址。
